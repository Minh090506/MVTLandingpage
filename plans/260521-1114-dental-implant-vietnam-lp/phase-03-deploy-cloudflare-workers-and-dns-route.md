# Phase 03 — Deploy to Cloudflare Workers + DNS Setup

**Priority:** P1 — final step, post-content-verified
**Status:** pending
**Depends on:** Phase 01 + Phase 02
**Est:** 15–30 min (mostly DNS propagation wait)

## Goal
Ship the unified `worker.js` to Cloudflare Workers and wire DNS so `implant.vietnamdentaltravel.com` serves the dental LP. Smoke test all critical paths.

## Pre-flight checks
- [ ] `worker.js` is freshly generated by `node build.js`
- [ ] No uncommitted changes other than the dental LP + build.js + deletions
- [ ] `wrangler.toml` worker name is `escape-myvivatour` (existing) — dental rides the same worker
- [ ] Cloudflare account has access to `vietnamdentaltravel.com` zone (if not, user must add it first)

## Deploy steps

### A. Local commit
```bash
git add pages/dental-implants-vietnam/ build.js worker.js
git rm worker-dental.js build-dental.js 2>/dev/null || true
git rm -rf pages/vietnamdentaltravel/ 2>/dev/null || true  # after the move in Phase 02
git commit -m "feat(dental): launch dental implants Vietnam LP at implant.vietnamdentaltravel.com"
```

### B. CF Workers deploy
Option 1 (CI/CD auto): `git push origin main` → GitHub Actions runs `deploy.yml`
Option 2 (manual): `npx wrangler deploy`

Verify output mentions the published URL e.g. `escape-myvivatour.workers.dev`.

### C. DNS / Routing
The current `wrangler.toml` likely only routes `*.myvivatour.com`. We need to add a Cloudflare Workers Route for `vietnamdentaltravel.com` zone.

**If vietnamdentaltravel.com is on Cloudflare:**
1. Cloudflare dashboard → Domains → `vietnamdentaltravel.com` → Workers Routes
2. Add route: `implant.vietnamdentaltravel.com/*` → worker `escape-myvivatour`
3. DNS: add `implant` CNAME → `escape-myvivatour.workers.dev` (proxied/orange cloud) — OR a placeholder A record `192.0.2.1` proxied
4. Wait 1–3 min for propagation

**If vietnamdentaltravel.com is NOT on Cloudflare:**
- Move zone to Cloudflare (or)
- Use the `workers.dev` subdomain: `escape-myvivatour.workers.dev/dental-implants-vietnam` — no custom domain in v1, plan domain migration as follow-up

**Wrangler.toml route alternative (instead of dashboard):**
```toml
routes = [
  { pattern = "escape.myvivatour.com/*", zone_name = "myvivatour.com" },
  { pattern = "happytours.myvivatour.com/*", zone_name = "myvivatour.com" },
  { pattern = "implant.vietnamdentaltravel.com/*", zone_name = "vietnamdentaltravel.com" }
]
```
Add the line, re-deploy via wrangler.

If something breaks post-deploy:
- Cloudflare dashboard → Workers → Versions → roll back to previous worker version (one click)
- OR git revert the commit + `npx wrangler deploy`
